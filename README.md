# cloak <3 
Harry Potter inspired tech fun project. Based on the combination of different open CV techniques.
In this project I have restricted the system to red color you can change the color according to your requirement.

# ?? What actually happen in the project ?? :
1. first when you launch the program , a camera will open
2. now first it capture the background with you
3. and after that since it is trigered to red color , therefore when you put a red color cloth on you or any anything , then that particular object will submerge with the screen.

# ?? What the theory behind ?? :
Actually in this project, we plan it to work exactly like that magical cloak of harry potter helps him to hide among the background.
The red color cloth actually hides in the background that why any changes become unvisible.
